# Volunteers

OpenRelief welcomes volunteers who want to help turn fragmented disaster information into structured, reviewable, privacy-aware records for humanitarian action.

This document explains what kind of volunteers OpenRelief needs and how different contributors can support the project.

## What Kind of Volunteers We Need

OpenRelief is an open-source humanitarian technology project. We especially welcome volunteers with experience or interest in:

* AI tools and large language models;
* AI agent development;
* software development;
* model evaluation and AI safety;
* data analysis;
* data modeling;
* disaster information analysis;
* mapping and GIS;
* privacy, security, and humanitarian ethics;
* documentation and open-source community work.

OpenRelief uses AI to support humanitarian information workflows, but human volunteers remain essential for review, judgment, safety, and accountability.

## Why Volunteers Matter

In disaster response, information is often scattered across social media, forms, spreadsheets, chat groups, field reports, public help requests, resource offers, and unofficial updates.

Volunteers help transform this fragmented information into useful humanitarian action by supporting:

* information collection;
* information structuring;
* needs classification;
* urgency triage;
* resource matching;
* situation reporting;
* data verification;
* privacy protection;
* AI workflow testing;
* software development;
* documentation and community support.

## Volunteer Roles

### AI Tool Operators

AI tool operators help test and use different AI systems in real humanitarian information workflows.

They may work on:

* using large language models to summarize disaster information;
* comparing outputs from different AI models;
* testing prompts for help-request structuring;
* checking whether AI outputs are accurate, useful, and safe;
* identifying hallucinations, missing details, or unsafe suggestions;
* turning messy information into structured drafts for human review.

Useful skills:

* experience using ChatGPT, Claude, Gemini, DeepSeek, Qwen, or other AI tools;
* ability to compare AI outputs critically;
* careful reading and fact-checking;
* awareness that AI suggestions are not final decisions.

### Prompt and Workflow Designers

Prompt and workflow designers help create reusable AI workflows for disaster information processing.

They may work on:

* help-request structuring prompts;
* needs classification prompts;
* urgency triage prompts;
* resource-matching prompts;
* situation-reporting prompts;
* multilingual summary prompts;
* safety-review prompts;
* human-in-the-loop review workflows.

Useful skills:

* prompt engineering;
* workflow design;
* structured thinking;
* humanitarian or emergency response knowledge;
* ability to design outputs that are easy for humans to review.

### AI Agent Developers

AI agent developers help build AI-assisted workflows and tools that support repetitive information-processing tasks.

They may work on:

* intake agents for public help requests;
* classification agents for disaster information;
* resource-matching agents;
* reporting agents;
* review-assistant agents;
* notification or routing agents;
* agent evaluation and failure testing;
* safety guardrails for agent behavior.

Useful skills:

* agent frameworks;
* API integration;
* tool calling;
* workflow automation;
* Python, TypeScript, or JavaScript;
* experience with OpenAI API or other LLM APIs;
* understanding of safety boundaries for autonomous systems.

### Software Developers

Software developers help build and maintain the OpenRelief platform.

They may work on:

* web interfaces for reviewing help requests;
* APIs for structured disaster information;
* databases for requests, resources, volunteers, tasks, and reports;
* dashboards for NGO coordinators;
* role-based access control;
* audit logs;
* notification systems;
* data import and export tools;
* integrations with forms, spreadsheets, maps, and messaging platforms.

Useful skills:

* frontend development;
* backend development;
* database design;
* API development;
* authentication and permissions;
* testing and CI;
* open-source collaboration;
* secure software engineering.

### Model Evaluation Volunteers

Model evaluation volunteers help test whether AI outputs are safe, reliable, and useful for humanitarian work.

They may work on:

* evaluation datasets;
* test cases for disaster information classification;
* safety cases for high-risk situations;
* hallucination checks;
* multilingual output evaluation;
* consistency testing across models;
* measuring false positives and false negatives;
* reviewing whether urgency triage prioritizes life-safety cases.

Useful skills:

* model evaluation;
* annotation;
* data labeling;
* error analysis;
* safety testing;
* statistics or machine learning basics;
* ability to define clear evaluation criteria.

* identifying resource gaps;

Useful skills:

* Python or R;
* SQL;
* data cleaning;

* dashboard design;
* statistical thinking;

### Disaster Information Analysts

Disaster information analysts help review and organize crisis-related information.

They may work on:

* monitoring public disaster information;
* identifying help requests;
* classifying needs;
* checking duplicate reports;
* comparing conflicting information;
* preparing situation briefs;
* supporting map-based or area-based views;

Useful skills:

* disaster information analysis;
* crisis informatics;

* careful verification;

* geocoding and location cleanup;

* shelter, road, hospital, and infrastructure mapping;
* visualizing resource gaps by area;

Useful skills:

* mapping tools;
* geospatial data;
* OpenStreetMap;
* QGIS;

* reviewing public reports before publication;
* defining human-in-the-loop rules;
* creating escalation rules;

Useful skills:

* privacy protection;
* humanitarian ethics;
* AI safety;
* data protection;
* responsible AI;
* experience with vulnerable populations or emergency response;
* careful judgment.

## How Volunteers Work Together

OpenRelief follows a human-in-the-loop approach.

AI can help process information, but humans remain responsible for reviewing, correcting, approving, and escalating high-risk cases.

Volunteer collaboration may include:

* AI-assisted structuring of incoming information;
* human review of AI outputs;
* verification of uncertain or conflicting reports;
* escalation to NGO coordinators or official emergency authorities;
* resource matching and follow-up;
* situation reporting;
* safety and privacy review;
* technical maintenance and system improvement.

## What We Value

We value volunteers who are:

* careful with sensitive information;
* respectful toward affected people and communities;
* willing to document their work;
* open to human review and correction;
* aware of the limits of AI;
* committed to privacy, safety, and accountability;
* comfortable working in open-source collaboration;
* willing to build tools that support, rather than replace, humanitarian responders.

## How to Contribute

You can start by:

* reviewing open issues;
* improving documentation;
* testing AI workflows;
* proposing data models;
* contributing sample evaluation cases;
* helping design prompts;
* building small software modules;
* reviewing safety and privacy risks.

OpenRelief welcomes contributors from technology, humanitarian response, public health, social work, emergency management, data science, AI safety, open-source communities, and civil society organizations.
